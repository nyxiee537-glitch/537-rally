# 537 Rally Planner — GitHub Pages公開手順

1. GitHubで新しいリポジトリ `537-rally` を作成します。無料プランではPublicを選びます。
2. このZIPを展開します。Add file → Upload filesから index.html / style.css / app.js / logo.png をリポジトリの一番上にアップロードし、Commit changesを押します。ZIP自体はアップロードしません。
3. Settings → Pages → Sourceで Deploy from a branch を選びます。
4. Branchは main、フォルダは /(root) を選び、Saveを押します。
5. 公開完了後、Settings → PagesのVisit siteから開きます。

URL形式: https://あなたのGitHubユーザー名.github.io/537-rally/

ファイルは最新の537版です。UTC入力・時刻調整・透過ロゴ・テキストコピーに対応。
入力は各ブラウザのlocalStorageに保存。サーバーでの予定共有・編集同期はありません。
「共有リンク」は作成時の予定をURL内に含みます。ページは公開されます。
